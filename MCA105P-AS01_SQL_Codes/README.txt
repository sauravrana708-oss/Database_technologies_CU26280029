MCA105P-AS01 SQL Codes
======================

Contains:
- Q01.sql through Q50.sql: each question and its SQL solution in a separate file.
- All_50_SQL_Solutions.sql: all solutions in one combined file.

SQL dialect: MySQL. The solutions use MySQL DDL features such as ENUM, CHANGE COLUMN,
FIRST, AFTER, and CREATE TABLE ... LIKE.

Important:
- Run statements in a suitable practice database, not on important production data.
- Some ALTER/DROP/TRUNCATE statements change or remove existing schema/data.
- Q16, Q25, and similar ALTER statements assume the named table/columns already exist.
- Q31 and Q46 add a new primary-key column without AUTO_INCREMENT, as the question does not request it.
